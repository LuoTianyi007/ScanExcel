# ScanExcel

离线二维码与条码扫描工具，支持批量记录和 Excel 导出。

## 下载

[点击下载 ScanExcel 安装包](https://github.com/LuoTianyi007/ScanExcel/releases/tag/v1.4.4)

进入下载页面后，在 Assets（资源）中选择：

- enhanced.apk：增强版安装包。
- compat.apk：兼容版安装包，增强版遇到问题时可尝试。

两个版本选择一个安装即可。
当前为测试版本，欢迎通过 Issues 反馈问题。

## 源码与许可

完整应用源码请下载发布附件中的 ScanExcel-1.4.4-source.zip。
